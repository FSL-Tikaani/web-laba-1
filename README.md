# Neo-Cinema Club

Тематический сайт о культовом научно-фантастическом кинематографе XXI века.

## Структура проекта
- `index.html` — семантическая разметка страницы, разделы, изображения и внешние ссылки.
- `styles.css` — оформление страницы, поддержка тёмной и белой темы, адаптивная вёрстка.
- `app.js` — клиентская логика и обработчики событий для интерактивных кнопок.
- `images/` — векторные иллюстрации в формате SVG.
